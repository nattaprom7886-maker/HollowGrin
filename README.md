# ตามหาครอบครัว (Family Search) — Minecraft 1.20.1 Forge mod

เรื่องราว: คุณคือชายที่อาศัยอยู่ในบ้านไม้เล็กๆ เมียและลูกทิ้งโน้ตไว้แล้วหนีไป
ภารกิจคือออกตามหาพวกเขาที่บ้านใหม่ ซึ่งอยู่ห่างจากจุดเกิด 3000 บล็อก (ทิศตะวันออก +X)

## วิธีเล่น
1. ใส่ไฟล์ `.jar` ในโฟลเดอร์ `mods` ของ Forge 1.20.1 (47.x)
2. เข้าโลกใหม่ จะถูกย้ายเข้าบ้านไม้ที่จุดเกิด อ่านโน้ตบนแท่นหนังสือ
3. เดินตามเข็มทิศไปทางทิศตะวันออก 3000 บล็อก
4. คลิกขวาที่ภรรยาหรือลูกเพื่อจบเกม

## ดาวน์โหลด .jar
ไปที่แท็บ **Actions** ใน GitHub > เลือก run ล่าสุด > ดาวน์โหลด artifact `familysearch-mod`

## Build เอง
ต้องใช้ Java 17

    gradle build

ไฟล์จะอยู่ที่ `build/libs/familysearch-1.0.0.jar`

## ปรับแต่ง
- ระยะทาง: `FamilySearchMod.DISTANCE`
- ข้อความโน้ต: `HouseBuilder.NOTE_TEXT`
- ไม่ต้องการเข็มทิศ: ลบส่วน compass ใน `ModEvents.onLogin`
