# Mr. Hollowgrin — "คุณยิ้มกลวง" (The Gracious Host)
Minecraft **1.20.1 · Forge 47.x · Java 17** — ผี 1 ตัว หลายร่าง ออกแบบเองทั้งหมด

## เนื้อเรื่อง
เล่ากันว่ามีหมู่บ้านหนึ่งต้อนรับแขกแปลกหน้า: ชายอ้วนใจดี สวมหมวกทรงสูงติดโบ ยิ้มกว้างจนไม่มีใครเห็นว่าตาของเขากลวงเปล่า
เขาแจกขนมปัง เล่นเกมกับเด็ก ๆ — เช้าวันรุ่งขึ้นหมู่บ้านว่างเปล่า เหลือแต่หมวกใบเดียวกับโบสีแดง
คุณยิ้มกลวงไม่มีหน้าของตัวเอง เขายืมหน้าชาวบ้าน และเขาเป็น "เจ้าบ้าน" ที่เข้าได้ต่อเมื่อได้รับเชิญ
**การจ้องมองคือคำเชิญ** ยิ่งคุณมองนาน ประตูยิ่งเปิดกว้าง — และเมื่อมันเปิดสุด เขาจะบอกว่า "Gotcha!" เกมซ่อนแอบจบแล้ว

## ร่างของเขา
- **ร่างหลัก = ชาวบ้านตัวจริงทุกอย่าง** (โมเดล เสื้อผ้าตามไบโอม อาชีพ ป้ายเลเวล คัดลอกจากชาวบ้านในหมู่บ้านนั้น) **ไม่เปลี่ยนเป็นร่างอื่นอีกต่อไป** ตอนเปิดเผยตัว ขากรรไกรของชาวบ้านจะอ้ากว้าง ข้างในมีฟันแหลม ลิ้น และมือสีดำยาวยื่นออกมาจับผู้เล่น
- **ร่างจริง (ตัวเลือก):** ชายอ้วนหมวกทรงสูง ถุงมือขาว ตากลวงลูกตาแดง ยังอยู่ในมอด เรียกได้ด้วย `/hollowgrin summon host` เท่านั้น ไม่โผล่เองในเกม

## ฉากจบเมื่อคุณดิ้นหลุด
ผีโยนคุณออกไป ร่างชาวบ้านสลายเป็นร่างจริง (ชายอ้วนหมวกสูง) -> ปรบมือให้คุณ -> โยนเพชร 1 เม็ดมาให้ -> ยกหมวกคำนับอย่างผู้ดี -> ควันล้อมตัว -> หายไป (ระหว่างนี้ผีทำร้ายไม่ได้และไม่โดนทำร้าย)

## ท่าไม้ตายเมื่อคุณต่อบล็อกหนีขึ้นที่สูง (3 บล็อกขึ้นไป)
1. ผีเปิดปาก แขนดำเอื้อมขึ้นแต่ไม่ถึง กระโดดแกล้งจับไม่ได้ (~3.5 วินาที)
2. แล้วนิ่ง ปิดปาก พูดภาษาอังกฤษ (มีข้อความขึ้นบนจอด้วย):
   "Do you really think I can't catch you? Hahaha... What a funny face. Then let's try the next level, shall we?"
3. เปิดปาก แขนยืดยาวออกมาถึงตัวคุณ ลากคุณเข้าหาตัวเอง -> เข้ามินิเกมบีบคอตามปกติ (กด Space)

## วิธีรับมืออื่น ๆ
- **ต่อบล็อกหนี:** ซื้อเวลาได้ แต่ผีจะใช้ท่าไม้ตายข้างบน
- **วางน้ำ:** ยืนแช่ในน้ำ ตัวลื่นเกินจะจับ/ลากไม่ได้ (ผีเองก็ช้าลงมากในน้ำ) แต่ยืนนานเกิน ~40 วินาทีผีจะเลิกไล่
- **ลาวา/ไฟ:** ผีโดนลาวาหรือไฟ จะตกใจปล่อยมือแล้วถอยหนี และลาวาทำให้เขาเดินข้ามไม่ได้
- **ไอรอนโกเลม:** ไม่โจมตีร่างชาวบ้านปลอม จะโจมตีเฉพาะตอนผีเปิดปากและมีมือออกมาเท่านั้น (โกเลมโจมตีตอนจับคุณ จะช่วยให้หลุดได้)

## พฤติกรรม
1. อยู่ในหมู่บ้าน (ชาวบ้าน 2 คนขึ้นไป) นานพอ (ค่าเริ่มต้น 5 นาที) เขาจะโผล่มา **ไม่โผล่ในสายตาคุณ** แต่ปลอมเป็นชาวบ้านในหมู่บ้าน
2. เดินเข้าหาช้า ๆ **สัญญาณเตือน (tells)**: ชาวบ้านจริงรอบตัวเขาส่ายหัวและไม่ยอมมองเขา, ได้ยินเสียงฮัมเพลงกล่อมเด็กแผ่ว ๆ, ถ้าจ้องเขา เสียงหัวใจคุณจะดังขึ้นเรื่อย ๆ
3. จ้องนานเกิน (ระยะใกล้ = ไวขึ้น), ตีเขา, หรือปล่อยให้ยืนชิดหลังคุณนานเกิน -> ชาวบ้านนิ่งสั่น -> ปากค่อย ๆ อ้า -> อ้ากว้างสุด มือดำยื่นออกมา ไล่ล่า (พุ่งกระโดดเมื่อใกล้)
4. จับคุณ: คุณลอยขึ้น กด Shift หนีไม่ได้ -> "Gotcha!" -> บีบ ~7 วินาที: **หลอดสีแดงขึ้นบนจอ กด Spacebar รัว ๆ เพื่อดิ้น** (หลอดลดลงเองเรื่อย ๆ) และ **จอค่อย ๆ มืดลง มืดสนิท = ตาย** (ระหว่างถูกบีบ HP ไม่ลด ตายตอนจอมืดสนิทเท่านั้น)
5. **ทางรอด:** กด Spacebar รัวจนหลอดเต็ม (ประมาณ 4–5 ครั้ง/วินาทีขึ้นไป) หรือตีเขาให้ได้ดาเมจรวม 24 (ปรับได้) ตอนถูกจับ เขาจะปล่อย มึนงง แล้วหายตัวไป / หรือหนีให้พ้นภายใน 40 วินาที

## Intro ตอนเข้าโลก (ใหม่)
จอดำสนิท -> ดวงตากลวงสีแดง 2 ดวงค่อย ๆ โผล่ในความมืด (กะพริบตาช้า ๆ ขยับเข้าใกล้ขึ้นเรื่อย ๆ) พร้อมเพลงกล่องดนตรีช้า ๆ เพี้ยนนิด ๆ
เขาพูดภาษาไทยกับผู้เล่น (มีซับไตเติลขึ้นทีละตัวอักษร): "สวัสดี คุณไม่คุ้นหน้าเลย อืมมมม ดูคุณจะเป็นเพื่อนใหม่สินะ อืมมมม hehehe อีกไม่นาน เราจะได้เล่นเกมด้วยกัน แต่เกมยังไม่เริ่มตอนนี้ นั่นไม่เป็นไรหรอก ฉันรอได้ อีกไม่นานหรอก เพื่อนใหม่"
จบแล้วตาหายไป เหลือแค่เสียงหัวเราะในความมืด แล้วจอดำค่อย ๆ จางเข้าสู่เกมปกติ (ประมาณ 51 วินาที)
- **เล่นเมื่อไหร่:** เฉพาะตอนเข้าโลกใหม่ครั้งแรก, โลกธรรมดา (ไม่ใช่ Superflat/Debug), โหมด Survival (Hardcore/Creative/Adventure ไม่เล่น), มิติ Overworld เท่านั้น
- **ครั้งเดียวต่อโลก:** จดแค่ค่า true/false 1 ค่าในข้อมูลผู้เล่นของโลกนั้น (วิธีปกติของ Minecraft) ไม่แตะไฟล์เกม โลกเก่าที่เล่นมานานแล้วจะไม่เล่น intro แม้ลงมอดทีหลัง
- **ระหว่าง intro:** ขยับ/กดปุ่มไม่ได้ (ESC ไม่ทำงาน) และผู้เล่นไม่ได้รับดาเมจ มีตัวกันเวลา server คอยปลดให้เองเสมอ
- **ทดสอบ:** `/hollowgrin intro` (OP) เล่นซ้ำได้ทุกเมื่อ · ปิดได้ด้วย `introEnabled=false` ใน config
- **เสียง:** `intro_voice.ogg` (เสียงพูดไทยสังเคราะห์ด้วย formant จึงเป็นเสียงหุ่นยนต์), `intro_music.ogg`, `intro_laugh.ogg` สร้างด้วย `tools/make_intro.py` ถ้าอัดเสียงจริงมาแทน ให้ใช้ชื่อไฟล์เดิม (mono .ogg) แล้วปรับตัวเลขเวลาใน `IntroTimeline.java`

## ติดตั้งแบบง่ายที่สุด (ไม่ต้องลงอะไรเลย: ใช้ GitHub)
1. สมัคร GitHub -> สร้าง repository ใหม่ -> อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github`)
2. แท็บ **Actions** -> workflow "Build mod jar" จะรันเอง -> ดาวน์โหลด artifact `hollowgrin-jar`
3. ใส่ `hollowgrin-1.8.0.jar` ในโฟลเดอร์ `mods` ของ Minecraft 1.20.1 + Forge 47.x

ติดตั้ง JDK 17 และ Gradle 8.1.1 แล้วรัน `gradle build` ในโฟลเดอร์นี้ -> ได้ไฟล์ที่ `build/libs/`
(ถ้า build.gradle มีปัญหา ให้ดาวน์โหลด Forge MDK 1.20.1 อย่างเป็นทางการ แล้วก๊อปโฟลเดอร์ `src` กับค่าใน `gradle.properties` ไปใส่)

## เสียง / โมเดล — แก้ไขได้
- เสียงทั้งหมดสังเคราะห์เองด้วย `tools/make_sounds.py` (เสียงพูด "Gotcha!" และเสียงหัวเราะเป็น formant synth จึงเป็นเสียงหุ่นยนต์ ๆ)
  **อยากได้เสียงพากย์จริง:** อัดเสียงแล้วแทนที่ `gotcha.ogg` / `laugh.ogg` (mono .ogg ชื่อเดิม) ได้เลย ไม่ต้องแก้โค้ด
- เท็กซ์เจอร์ผีวาดด้วย `tools/make_textures.py` (128x192) แก้แล้วรันใหม่ได้ ส่วนร่างชาวบ้านปลอมใช้เท็กซ์เจอร์ชาวบ้านของ Minecraft เอง
- โมเดลเขียนเป็นโค้ดใน `client/HostModel.java`

## ลูกเล่นหมา (ใหม่ใน 1.7)
1. สั่งหมาที่เลี้ยงไว้ให้ **นั่งรอ** ในบ้านชาวบ้าน (บ้านต้องมีหลังคาและอยู่ในหมู่บ้าน)
2. ออกไปไกลจากบ้าน (ตั้งแต่ 28 บล็อก เช่น ออกไปข้างนอกหรือลงเหมือง) นานพอ (ค่าเริ่มต้น 20 วินาที) แล้วกลับมา
3. พอกลับมาใกล้ ๆ **ตอนที่คุณไม่ได้มองหมา** หมาจะหายไปเงียบ ๆ ไม่มีเสียง ไม่มีควัน
4. เมื่อคุณเข้าบ้านแล้วเดินออกมาข้างนอกเพื่อตามหา คุณยิ้มกลวง (หน้าตาเป็นชาวบ้าน) จะยืน **หันหลังให้** อยู่ข้างนอก ไกลประมาณ 10-16 บล็อก ฮัมเพลงเบา ๆ
5. เมื่อคุณจ้องหลังเขาพอสมควร (หรือเดินเข้าใกล้) **หัวเขาหมุนกลับมาหาคุณทีละน้อย** -> จ้องหน้าคุณ (เสียงหัวใจดัง) -> **หมุนตัวทั้งตัวมา** -> **ชูหัวหมาของคุณขึ้นมาให้ดู** (หมาร้องครวญคราง เขาหัวเราะ) -> ควันล้อมตัว -> หายไป
6. หลังจากนั้น **เลี้ยงหมาไม่ได้อีกตลอดไป** (ป้อนกระดูกแล้วหมาไม่ยอมเชื่อง)
- ระหว่างฉากนี้ผีทำร้ายไม่ได้ และถ้าไม่เคยมองเขาเลย 45 วินาที เขาก็หายไปเอง (หมาก็ยังหายและเลี้ยงไม่ได้เหมือนเดิม)
- ใช้ได้เฉพาะ Overworld ที่ไม่ใช่ Peaceful และผู้เล่นไม่ใช่ Creative
- ทดสอบ: `/hollowgrin dog` (เริ่มฉากทันที) / `/hollowgrin dogreset` (ปลดคำสาป กลับมาเลี้ยงหมาได้)
- ปิดฟีเจอร์ได้ใน config: `dogTrick = false` / ปรับเวลาที่ต้องออกห่าง: `dogAwaySeconds`

## โมเดลใหม่ของคุณยิ้มกลวง (1.7)
ร่างจริง (`/hollowgrin summon host` และฉากอำลา) ปรับตามภาพสเก็ตช์: สูงผอม ไหล่กว้างมาก คอยาว หน้ายาวแคบ หูใหญ่ เบ้าตาดำโบ๋ใหญ่ มีลูกตาแดงจุดเล็ก ๆ ยิ้มฟันแหลมจรดแก้ม หมวกทรงสูงปีกกว้างแบน สวมเอี๊ยม แขนยาว ถุงมือขาว
แก้ไขรูปร่างที่ `HostModel.java` และสีที่ `tools/make_textures.py` (รัน `python3 tools/make_textures.py` เพื่อสร้าง PNG ใหม่)

## มินิเกมของคุณยิ้มกลวง (1.8 — อัปเดตสุดท้าย)
"อีกไม่นาน เราจะได้เล่นเกมด้วยกัน" — ตามที่เขาบอกไว้ใน intro ตอนนี้เล่นได้จริงแล้ว 3 เกม
**ใครก็เล่นได้ ไม่ต้องเป็น OP** พิมพ์ `/hollowgames` (หรือ `/hgames`) จะขึ้นเมนู กดที่บรรทัดเกมในแชทเพื่อเริ่มเล่นได้เลย · `/hollowgames stop` เพื่อเลิกเล่น
ทุกเกมทำงานฝั่งเซิร์ฟเวอร์ ส่งเป็นข้อความกลางจอ / action bar / บอสบาร์ **ไม่มีโค้ดฝั่งไคลเอนต์ใหม่ ไม่มีดาเมจ ไม่แตะไฟล์ ไม่แตะเซฟ** ถ้าเกมเกิดบั๊กจะแค่จบเกมนั้นและบันทึกลง log เท่านั้น

### 1) ไฟเขียว ไฟแดง — `/hollowgames redlight`
- เขาเรียก "เขียว" (วิ่งได้) และ "แดง" (ห้ามขยับ) สลับกันแบบสุ่มเวลา วิ่งสะสมให้ครบ **80 บล็อก** ภายใน 150 วินาที
- ก่อนเปลี่ยนเป็นแดงเล็กน้อยจะได้ยินเสียงหัวใจเตือน ตอนแดงมีเวลาตั้งตัว ~0.6 วินาทีก่อนเริ่มตรวจ (กระโดดอยู่กับที่ได้ แต่ห้ามเดินไปไหน)
- ขยับตอนแดง = "Gotcha!" แพ้ (ตาบอด 2 วินาที ไม่มีดาเมจ) · ผ่าน = รางวัล **เพชร 1 เม็ด**

### 2) กล่องดนตรี — `/hollowgames musicbox`
- เล่นทำนองระฆังแก้ว พร้อมขึ้นเลขช่อง hotbar ของแต่ละโน้ตกลางจอ จากนั้นถึงตาคุณ: กดปุ่ม **1–9** ตามลำดับเดิม
- 5 รอบ ทำนองยาวขึ้นรอบละ 1 โน้ต (3 -> 7 โน้ต) ช่องที่เลือกต้องค้างไว้ ~0.2 วินาทีถึงจะนับ ดังนั้นเลื่อนลูกกลิ้งเมาส์ผ่านช่องอื่นไม่ถือว่าผิด
- กดผิด = แพ้ (บอกด้วยว่าที่ถูกคือปุ่มอะไร) · ผ่านครบ 5 รอบ = รางวัล **มรกต 4 เม็ด**

### 3) หลบก้อนหิมะ — `/hollowgames dodge`
- เขาปาก้อนหิมะใส่จากรอบทิศ เร็วขึ้นเรื่อย ๆ นาน **45 วินาที** มี **3 ชีวิต** ก้อนหิมะเล็งนำหน้าทิศที่คุณวิ่งเล็กน้อย และบินเป็นเส้นตรง ต้องเปลี่ยนทิศหลบ
- ก้อนหิมะไม่ทำดาเมจเลย และหายไปทันทีเมื่อโดนคุณ (ผนังบังก็หายไปเฉย ๆ) · ชีวิตหมด = แพ้ · รอดครบ = รางวัล **แอปเปิลทอง 2 ลูก**

### กติกาทั่วไป
- เล่นได้ทีละเกมต่อคน เกมจะจบเองถ้าคุณตาย ออกจากเกม เปลี่ยนมิติ หรือโดนคุณยิ้มกลวง (ตัวจริง) จับ
- รางวัลไม่ให้ในโหมด Creative และให้ซ้ำเกมเดิมได้ทุก 10 นาที (กันฟาร์ม) · ตั้งค่าใน config: `gamesEnabled` (ปิดเกมทั้งหมด), `gameRewards` (ปิดรางวัล), `gameRewardCooldown` (วินาที)
